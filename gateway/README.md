# Gateway Setup Guide

This gateway uses **Nginx** (Stream Proxy) and **Wireguard** to forward traffic to the internal server. It uses **CrowdSec** for security monitoring (SSH & Logs).

## CrowdSec Firewall Bouncer Setup (Host)

Since CrowdSec is running in a container (`homelab_gateway-crowdsec-1`), but we want to block traffic at the host firewall level (iptables/nftables), we must install the **CrowdSec Firewall Bouncer** directly on the host OS.

### 1. Install the Bouncer
**For Debian/Ubuntu:**
```bash
# Update repositories (assuming crowdsec repo is already added, if not see official docs)
sudo apt update

# Install the bouncer (choose iptables or nftables based on your system)
sudo apt install crowdsec-firewall-bouncer-iptables
# OR
sudo apt install crowdsec-firewall-bouncer-nftables
```

### 2. Generate API Key
Generate an API key from the **CrowdSec container**:
```bash
docker exec -it homelab_gateway-crowdsec-1 cscli bouncers add firewall-bouncer-host
```
*Copy the API key generated by this command.*

### 3. Configure the Bouncer
Edit the configuration file on the **host**:
```bash
sudo nano /etc/crowdsec/bouncers/crowdsec-firewall-bouncer.yaml
```

**Required Changes:**
1.  **API Url:** Set to localhost (since the agent is exposing port 8080).
    ```yaml
    api_url: http://127.0.0.1:8080/
    ```
2.  **API Key:** Paste the key you generated in Step 2.
    ```yaml
    api_key: <YOUR_GENERATED_KEY>
    ```
3.  **Docker Support (Crucial):** Uncomment the `iptables_chains` section to ensure Docker containers are protected. By default, Docker bypasses standard iptables rules. The `DOCKER-USER` chain allows us to filter traffic *before* it reaches the containers.
    ```yaml
    iptables_chains:
      - DOCKER-USER
      - INPUT
      # - FORWARD # (Optional, depending on needs)
    ```

### 4. Restart the Bouncer Service
```bash
sudo systemctl restart crowdsec-firewall-bouncer
```

### 5. Verify
Check the logs to ensure it connected to the Agent:
```bash
sudo tail -f /var/log/crowdsec-firewall-bouncer.log
```
You should see "Processing new and deleted decisions".
